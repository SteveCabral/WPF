1. Project Overview

Goal

Create a minimal WPF application that validates PDFsharp-WPF can:

  • Open existing PDF files
  • Count pages accurately
  • Read page dimensions in points
  • Render pages with acceptable quality
  • Display rendered pages in a WPF UI

Workflow

Open PDF ↓ Count pages ↓ Read dimensions of every page ↓ Render Page 1 ↓ Display Page 1 in WPF

Success Criteria

  • ✓ Opens real-world PDFs successfully
  • ✓ Accurate page counts and dimensions
  • ✓ Clear, high-quality page rendering
  • ✓ Acceptable performance with multi-page PDFs
  • ✓ No critical compatibility issues

2. Why Start with a Proof of Concept?

Critical Technical Question: Can PDFsharp-WPF render PDF pages with acceptable quality and performance?

From the design document (Section 15): "The most important technical question to validate early is page rendering."

Why Validate Rendering First?

A minimal test application should validate core PDF functionality before building the full UI. This approach is preferable to building the entire application first and discovering later that:

  • Rendering quality is inadequate for thumbnails or previews
  • PDF compatibility is limited (some PDF versions don't work)
  • Performance is poor with large documents
  • Memory usage is excessive
Design Principle: If the proof of concept works correctly with representative PDFs, the rest of the application can be built around the result.

4. WPF Concepts Primer

What is WPF?

Windows Presentation Foundation (WPF) is a UI framework for building Windows desktop applications. It uses XAML (eXtensible Application Markup Language) for UI design and C# for application logic.

Key WPF Concepts in This Application

XAML (UI Markup)

XAML is an XML-based language for defining user interfaces. It's declarative, meaning you describe what you want, not how to create it.

<Button x:Name="OpenPdfButton" 
        Content="Open PDF" 
        Click="OpenPdfButton_Click"/>

This creates a button with the text "Open PDF" that calls OpenPdfButton_Click when clicked.

Controls

WPF provides many built-in controls. This application uses:

  • Window - The main application window
  • Grid - Layout container that arranges children in rows/columns
  • StackPanel - Stacks children vertically or horizontally
  • Button - Clickable button
  • TextBlock - Read-only text display
  • ListBox - Scrollable list of items
  • Image - Displays images/bitmaps
  • ScrollViewer - Provides scrolling for content
  • Border - Draws a border around content

Events

Events connect UI actions to C# code. When a user clicks a button, the Click event fires.

// XAML
<Button Click="OpenPdfButton_Click"/>

// C# Code-Behind
private void OpenPdfButton_Click(object sender, RoutedEventArgs e)
{
    // Handle button click
}

Code-Behind

The C# file (MainWindow.xaml.cs) that contains the logic for the XAML UI (MainWindow.xaml).

Data Binding (Not Used Yet)

Data binding automatically synchronizes UI with data. We'll use this in future phases with the MVVM pattern.

Learning Note: This proof of concept uses a simple code-behind approach. The full application will use MVVM (Model-View-ViewModel) for better separation of concerns.

5. PDFsharp Introduction

What is PDFsharp?

PDFsharp is a .NET library for creating, reading, and modifying PDF documents. It provides a comprehensive API for PDF manipulation without requiring Adobe Acrobat.

PDFsharp-WPF vs. PDFsharp-GDI

  • PDFsharp-wpf - Uses WPF graphics (recommended for WPF apps)
  • PDFsharp-gdi - Uses GDI+ graphics (for WinForms apps)

Core Classes Used in This Application

PdfDocument

Represents a PDF document. Contains pages, metadata, and document properties.

// Open an existing PDF
PdfDocument document = PdfReader.Open(filePath, PdfDocumentOpenMode.Import);

// Get page count
int pageCount = document.PageCount;

// Access pages
PdfPage firstPage = document.Pages[0];

PdfReader

Used to open and read PDF files.

PdfDocument doc = PdfReader.Open("sample.pdf", PdfDocumentOpenMode.Import);

PdfPage

Represents a single page in a PDF document. Provides access to page dimensions and content.

PdfPage page = document.Pages[0];
double widthInPoints = page.Width.Point;
double heightInPoints = page.Height.Point;

XGraphics

Provides drawing capabilities. Used for rendering PDF content to WPF visuals.

PDF Points vs. Inches

PDFsharp uses points as the unit of measurement:

72 points = 1 inch

Page dimensions are returned in points, which you can convert to inches:

double widthInInches = page.Width.Point / 72.0;
double heightInInches = page.Height.Point / 72.0;

MainWindow.xaml.cs - Core Logic

Class Fields

private PdfDocument? _currentPdfDocument;
private string? _currentPdfPath;

Store the currently open PDF document and its file path.

OpenPdfButton_Click - File Selection

private void OpenPdfButton_Click(object sender, RoutedEventArgs e)
{
    // Create file dialog
    OpenFileDialog openFileDialog = new OpenFileDialog
    {
        Filter = "PDF Files (*.pdf)|*.pdf|All Files (*.*)|*.*",
        Title = "Select a PDF File",
        InitialDirectory = Environment.GetFolderPath(
            Environment.SpecialFolder.MyDocuments)
    };

    // Show dialog and load PDF if user selected a file
    if (openFileDialog.ShowDialog() == true)
    {
        try
        {
            // Validate file exists and has .pdf extension
            LoadPdf(openFileDialog.FileName);
        }
        catch (Exception ex)
        {
            // Show error message
        }
    }
}

LoadPdf - Open and Analyze

private void LoadPdf(string filePath)
{
    // Close previous document
    _currentPdfDocument?.Dispose();

    // Open new document
    _currentPdfDocument = PdfReader.Open(filePath, PdfDocumentOpenMode.Import);
    _currentPdfPath = filePath;

    // Display filename
    FileNameTextBlock.Text = $"File: {Path.GetFileName(filePath)}";

    // Count pages
    int pageCount = _currentPdfDocument.PageCount;
    PageCountTextBlock.Text = $"Pages: {pageCount}";

    // Read dimensions
    ReadPageDimensions();

    // Render first page
    if (pageCount > 0)
    {
        RenderPage(0);
    }
}

ReadPageDimensions - Extract Page Info

private void ReadPageDimensions()
{
    PageDimensionsListBox.Items.Clear();

    for (int i = 0; i < _currentPdfDocument.PageCount; i++)
    {
        PdfPage page = _currentPdfDocument.Pages[i];
        double width = page.Width.Point;
        double height = page.Height.Point;
        string text = $"Page {i + 1}: {width:F1} x {height:F1} pts";
        PageDimensionsListBox.Items.Add(text);
    }
}

RenderPage - Display PDF Page

private void RenderPage(int pageIndex)
{
    PdfPage page = _currentPdfDocument.Pages[pageIndex];

    // Calculate render size at 150 DPI
    double scaleFactor = 150.0 / 72.0;
    int width = (int)(page.Width.Point * scaleFactor);
    int height = (int)(page.Height.Point * scaleFactor);

    // Create drawing visual
    DrawingVisual visual = new DrawingVisual();
    using (DrawingContext dc = visual.RenderOpen())
    {
        // Rendering code (simplified in proof of concept)
        dc.DrawRectangle(Brushes.White, null, new Rect(0, 0, width, height));
        // ... actual PDF rendering would go here
    }

    // Convert to bitmap
    RenderTargetBitmap bitmap = new RenderTargetBitmap(
        width, height, 150, 150, PixelFormats.Pbgra32);
    bitmap.Render(visual);

    // Display
    PdfPreviewImage.Source = bitmap;
}
Note: The current rendering implementation is a placeholder that validates the pipeline. Full PDF content rendering using XPdfForm requires additional implementation in future phases.

9. PDF Page Dimensions Reference

Units of Measurement

72 points = 1 inch

Common Page Sizes

Page Size Inches Points Use Case
US Letter 8.5 × 11 612 × 792 Standard US documents
US Legal 8.5 × 14 612 × 1008 Legal documents
A4 8.27 × 11.69 595 × 842 International standard
Tabloid/Ledger 11 × 17 792 × 1224 Large format

Detecting Page Sizes

double width = page.Width.Point;
double height = page.Height.Point;

const double tolerance = 5.0; // Allow 5 point variance

if (Math.Abs(width - 612) < tolerance && Math.Abs(height - 792) < tolerance)
{
    // US Letter
}
else if (Math.Abs(width - 612) < tolerance && Math.Abs(height - 1008) < tolerance)
{
    // US Legal
}
else if (Math.Abs(width - 595) < tolerance && Math.Abs(height - 842) < tolerance)
{
    // A4
}

Portrait vs. Landscape

if (page.Height > page.Width)
{
    // Portrait
}
else if (page.Width > page.Height)
{
    // Landscape
}
else
{
    // Square
}
Learning Note: Using a tolerance (e.g., 5 points) when detecting page sizes accounts for floating-point precision and slight variations in PDF generation.

11. Common Issues & Troubleshooting

Issue: "Could not load file or assembly 'PDFsharp...'"

Cause: PDFsharp-wpf package not installed or wrong version.

Solution:

dotnet restore
# Or manually add to .csproj:
<PackageReference Include="PDFsharp-wpf" Version="6.2.4" />

Issue: PDF Opens But Shows "0 Pages"

Cause: PDF is corrupted or uses unsupported features.

Solution: Try opening the PDF in Adobe Reader to verify it's valid.

Issue: "Access Denied" Error

Cause: File is locked by another application or lacks permissions.

Solution: Close any programs using the PDF, check file permissions.

Issue: Incorrect Page Dimensions

Cause: Page rotation or crop box not accounted for.

Solution: Check page.Rotate property, use page.MediaBox for full dimensions.

Issue: Rendering is Blank or Wrong

Cause: Current implementation uses placeholder rendering.

Solution: This is expected in the proof of concept. Full rendering requires XPdfForm implementation.

Issue: Out of Memory with Large PDFs

Cause: Loading all pages into memory at once.

Solution: In future phases, use lazy loading and page caching strategies.

Debugging Tips

  • Use Visual Studio breakpoints to step through code
  • Check Output window for exception details
  • Wrap suspicious code in try-catch with detailed logging
  • Test with simple single-page PDFs first
  • Validate PDFs in Adobe Reader before testing in the app

Useful Diagnostic Code

// Log detailed PDF information
Console.WriteLine($"PDF Version: {document.Version}");
Console.WriteLine($"Page Count: {document.PageCount}");
Console.WriteLine($"File Size: {new FileInfo(filePath).Length} bytes");

foreach (PdfPage page in document.Pages)
{
    Console.WriteLine($"Page: {page.Width} x {page.Height}, Rotation: {page.Rotate}");
}
