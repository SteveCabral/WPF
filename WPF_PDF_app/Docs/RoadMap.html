Version 0.3.0 - Page Information and Filtering

Phase 3 | Classification and Filtering

Planned Features

  • 🔜 Create PageSizeCategory enum (Letter, Legal, A4, Other)
  • 🔜 Classify pages by physical size with tolerance
  • 🔜 Display page size on thumbnails (badge/label)
  • 🔜 Add filter ComboBox (All/Letter/Legal/A4/Other)
  • 🔜 Add Portrait/Landscape orientation filters
  • 🔜 Show/hide pages based on active filter
  • 🔜 Display page number on each thumbnail
  • 🔜 Show page dimensions in tooltip

Page Size Detection

  • US Letter: 612 × 792 points (8.5 × 11 inches)
  • US Legal: 612 × 1008 points (8.5 × 14 inches)
  • A4: 595 × 842 points (8.27 × 11.69 inches)
  • Tolerance: ±5 points for floating-point precision

Success Criteria

  • All pages correctly classified by size
  • Filters work instantly (no lag)
  • Visual indicators clearly show page properties
  • Mixed-size documents handled correctly

Development Guidelines

Version Increment Rules

  • Patch (0.1.x): Bug fixes, documentation updates, minor UI tweaks
  • Minor (0.x.0): New features, completing a phase from design document
  • Major (x.0.0): Major milestones (v1.0 = first production, v2.0 = major redesign)

Release Checklist

Before releasing any version:

  1. ✅ All planned features implemented
  2. ✅ Code compiles without warnings
  3. ✅ Manual testing completed
  4. ✅ Documentation updated
  5. ✅ Version number updated in code
  6. ✅ README.md updated
  7. ✅ RoadMap.html updated
  8. ✅ Git tag created (v0.x.0)
  9. ✅ Release notes written

Branching Strategy

  • main - Stable releases only
  • develop - Active development
  • feature/phase-X - Individual phase development
  • hotfix/issue-X - Critical bug fixes
