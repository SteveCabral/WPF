How to Update Version:
----------------------
When moving to the next phase (e.g., 0.2.0):

1. Update MainWindow.xaml.cs:
   - Change AppVersion constant
   - Change AppPhase constant if needed

2. Update MainWindow.xaml:
   - Update Title attribute (if desired)
   - Update header TextBlock version

3. Update README.md:
   - Update "Current Version" section
   - Update version table
   - Update status badges

4. Update Docs/RoadMap.html:
   - Mark previous version complete
   - Update "Current Status" section
   - Update timeline badges

5. Update this VERSION.txt file

6. Git tag the release:
   git tag -a v0.x.0 -m "Version 0.x.0 - Phase Description"
   git push origin v0.x.0
